# landing page e-commerce pour une montre connectée de luxe

Généré automatiquement par un système multi-agents.

## 🏗️ Architecture
- **Type**: landing_page
- **Backend**: FastAPI
- **Frontend**: HTML/CSS/JS + Jinja2

## 📁 Structure
- `main.py` - Serveur FastAPI avec routes pour la landing page
- `templates/index.html` - Page d'accueil avec présentation du produit
- `static/style.css` - Styles CSS pour la landing page
- `static/script.js` - JavaScript pour interactions et animations

## 🚀 Lancement
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
